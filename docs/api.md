# NEBULA HTTP API

Generated by `scripts/gen-api-doc.py` from the running FastAPI app; machine-readable contract: `packages/contracts/openapi.json` (also served at `/api/openapi.json`, Swagger UI at `/api/docs`).

* Success: `{"data": …, "request_id": "…", "job_id"?: "…"}` · Error: `{"error": {"code", "message", "details"}, "request_id"}` with an HTTP status.
* Auth: session cookie `nebula_session` (HttpOnly, SameSite=Strict). Every POST/PUT/PATCH/DELETE needs `Origin: http://127.0.0.1:<port>` and `x-csrf-token` (from `/api/v1/auth/state`).
* `Idempotency-Key` header is honoured on POST /agents, POST /agents/{id}/tasks, DELETE /agents/{id}, POST /setup/install.
* Live stream: `POST /api/v1/agents/{id}/live/connect` → `ws://127.0.0.1:<port>/api/v1/live/ws/{session_id}?token=…` (subprotocol `binary`, raw RFB). Token is single-use and short-lived.
